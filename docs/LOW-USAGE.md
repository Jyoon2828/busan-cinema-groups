# Firebase 통신을 줄인 구성

학생이 각자 태블릿으로 들어오는 버전입니다. 25명과 교사 화면 한 탭, 전자칠판 한 탭을 사용하면 약 27개 활성 탭 규모입니다. 실제 연결 수는 Firebase 콘솔에서 확인합니다.

- 사진 17개와 거학이는 배포 파일에서 읽습니다. Firebase Storage와 데이터베이스에 사진을 올리지 않습니다.
- 학생 등록은 모둠·번호·이름·익명 인증 UID와 번호 중복 방지용 작은 색인을 한 번 기록합니다.
- 입력 중인 메모는 브라우저에 저장합니다. 글자를 입력할 때마다 Firebase에 보내지 않습니다.
- 학생은 자기 모둠 배정·기록이·작은 제출 요약과 작은 수업 상태만 구독합니다. 전체 학생 명단이나 다른 모둠의 글을 읽지 않습니다.
- 모둠 결과는 기록이 한 명이 제출할 때 본문과 작은 제출 요약을 한 번에 갱신합니다. 가장 최근 제출본만 유지합니다.
- 교사는 여섯 모둠의 배정·기록이·제출 요약과 최대 40명의 작은 입장 정보만 구독합니다.
- 전자칠판은 수업 장면 번호와 여섯 모둠의 배정·제출 요약을 구독합니다. 학생 명단은 요청할 때만 읽습니다.
- 발표 본문은 선택한 모둠만 읽고 수정 번호별로 재사용합니다. 모든 모둠의 긴 본문을 계속 구독하지 않습니다.
- 타이머는 종료 시각만 한 번 저장합니다. 초 단위 화면 표시는 기기 안에서 계산합니다.
- 사용하지 않는 탭은 닫습니다. 보이지 않는 화면의 구독은 해제하고, 다시 보이면 작은 상태부터 연결합니다. 주기적인 전체 데이터 조회나 접속 확인용 하트비트는 없습니다.
- 수업 기록을 저장하고 보관을 마친 수업은 삭제합니다. 7일 만료는 자동 삭제가 아닙니다.

Realtime Database의 Spark 무료 한도는 2026-11-09 공식 안내 기준 동시 연결 100개, 저장 1GB, 다운로드 월 10GB입니다. 같은 프로젝트를 사용하는 다른 앱의 사용량도 합산됩니다. 연결·암호화 등의 부가 통신도 포함되므로 한 수업의 사용량을 일정 값으로 보장하지 않습니다. Realtime Database의 사용량(Usage)에서 확인합니다.
