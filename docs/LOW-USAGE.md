# Firebase 사용량을 줄이는 구성

이 앱은 Firebase Authentication과 Realtime Database를 사용합니다. 사진·영상 파일은 올리지 않고, 모둠의 글·영화관 ID·근거 ID·제출 상태·작은 발표 제어 정보만 저장합니다. Cloud Storage, Firestore, Cloud Functions는 사용하지 않습니다.

## 언제 통신하나요?

| 활동 | 처리 방식 |
| --- | --- |
| 글 입력·수정 | 대표 기기 브라우저에 초안 저장. 글자마다 서버에 보내지 않음 |
| 영화관 사진·읽기 자료 보기 | 배포된 앱 파일을 읽음. 사진을 Realtime Database에서 내려받지 않음 |
| 모둠 입장 | 인증 후 해당 수업과 해당 모둠 정보를 확인 |
| 모둠 활동 중 | 자신의 배정·수업 열림 여부·단계처럼 작은 정보만 확인 |
| 제출·다시 제출 | 버튼을 누를 때 작성한 글과 근거 ID, 제출 요약을 전송 |
| 교사·전자칠판 대기 | 해당 수업의 모둠 여섯 개 제출 요약을 구독 |
| 발표할 모둠 선택 | 발표 모둠·화면 같은 작은 제어 정보만 동기화 |
| 발표 본문 보기 | 선택한 모둠의 제출본을 읽고 수정 번호별로 기기에 보관하여 재사용 |
| 수업 기록 내려받기 | 교사가 요청할 때 제출 기록을 읽어 JSON으로 저장 |

입력 중인 글 전체, 사진 원본, 접속자 목록, 초 단위 시간, 하트비트는 실시간으로 계속 보내지 않습니다. 주기적으로 전체 내용을 다시 읽는 폴링도 사용하지 않습니다. 화면을 떠나면 불필요한 구독을 해제하며, 앱이 보이지 않거나 활동하지 않을 때는 연결을 줄이도록 구성합니다.

## 수업 운영으로 줄이는 방법

- 모둠별 대표 기기 한 대를 사용합니다. 여섯 모둠과 교사 화면 한 탭, 전자칠판 한 탭이면 활동 연결은 약 여덟 개 탭 규모입니다.
- 교사·전자칠판·학생 화면을 같은 기기에 여러 탭으로 계속 열어 두지 않습니다. 쓰지 않는 탭을 닫습니다.
- 교사 화면은 모둠의 작은 제출 요약을 보며 대기합니다. 모든 모둠의 긴 본문을 계속 구독하지 않습니다.
- 토의 중에는 여러 번 제출하지 않고, 내용이 정리되었을 때 제출합니다. 수정이 필요할 때만 다시 제출합니다.
- 교사는 수업 기록을 내려받은 뒤 보관이 끝난 수업을 삭제합니다. 7일 만료는 접근 제한이며 자동 삭제가 아닙니다.
- 같은 Firebase 프로젝트를 사용하는 다른 수업 앱의 연결·저장·다운로드도 함께 살펴봅니다.

## 무료 한도와 실제 사용량

2026년 11월 9일 확인한 Firebase 공식 안내에서 Realtime Database **Spark 요금제**의 한도는 동시 연결 100개, 저장 1GB, 다운로드 월 10GB입니다. 연결 한 개는 연결된 브라우저 탭·기기 등에 해당하며, 학생 인원수만으로 계산하지 않습니다.

사진을 Firebase에 저장하지 않더라도 인증·데이터 조회·연결 유지에는 통신이 있습니다. 실제 다운로드에는 프로토콜·암호화 통신 등 부가 전송도 포함됩니다. 이 문서는 무료 사용이나 일정한 사용량을 보장하지 않습니다. 프로젝트에서 다른 앱도 운영한다면 한도와 사용량을 함께 확인해야 합니다.

Firebase 콘솔의 Realtime Database → Usage에서 **Connections, Storage, Downloads, Load**를 확인합니다. 먼저 대표 태블릿·교사·전자칠판으로 시험 수업을 한 뒤 평소 사용량을 확인하는 것이 좋습니다.

공식 확인 자료:

- Firebase 요금: https://firebase.google.com/pricing
- Realtime Database 연결 한도: https://firebase.google.com/docs/database/usage/limits
- 사용량과 과금 계산: https://firebase.google.com/docs/database/usage/billing
- 구독·데이터 구조·연결 최적화: https://firebase.google.com/docs/database/usage/optimize

교사·전자칠판은 배정 변경을 놓치지 않도록 여섯 모둠의 작은 배정 정보도 구독합니다. 이것은 조사 본문이나 사진을 읽는 구독이 아니며, 같은 데이터베이스 연결 안에서 처리합니다.
