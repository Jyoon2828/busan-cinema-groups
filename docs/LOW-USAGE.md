# Firebase 통신을 줄인 구성

사진과 읽기 자료는 배포 파일에서 읽습니다. Firebase에는 입장·작은 수업 상태·개인 의견·모둠 결과의 텍스트만 저장합니다. Analytics, Storage, Functions, Firestore는 사용하지 않습니다.

- 학생 등록은 모둠·번호·이름·익명 인증 UID와 번호 중복 방지 색인을 한 번 기록합니다.
- 입력 중인 개인 의견과 최종 두 항목은 브라우저에 저장합니다. 글자를 입력할 때마다 Firebase에 보내지 않습니다.
- 개인 의견은 게시 버튼을 누를 때만 본문과 작은 참여 요약을 함께 갱신합니다. 학생 번호마다 최신 글 한 개로 덮어쓰며 이력을 쌓지 않습니다.
- 학생은 작은 수업 상태와 자기 모둠의 배정·기록이·제출 요약·개인 의견만 구독합니다. 다른 모둠의 게시글이나 전체 명단은 읽지 않습니다. 개인 글은 180자 이내입니다.
- 교사 화면은 여섯 모둠 배정·기록이·제출 요약, 최대 40명의 입장 정보와 작은 개인 의견 참여 요약만 구독합니다. 개인 의견 본문은 해당 모둠 게시판을 열 때 한 번 읽습니다.
- 전자칠판은 작은 수업 상태·배정·제출 요약·참여 요약을 구독합니다. 학생 명단과 개인 게시글은 필요한 화면을 열 때만 읽습니다.
- 최종 모둠 결과는 기록이가 제출할 때만 소개 120자·의미 100자와 작은 제출 요약을 함께 갱신합니다. 최근 최종본 하나만 유지합니다.
- 발표 본문은 선택한 모둠만 읽고 수정 번호별로 재사용합니다. 전 모둠의 긴 본문을 계속 구독하지 않습니다.
- 길어진 자료의 설명 페이지, 사진 넘김, 질문 선택, 기기 메모는 서버에 보내지 않습니다.
- 타이머는 종료 시각만 한 번 저장합니다. 초 단위 표시는 기기 안에서 계산합니다.
- 보이지 않는 탭의 구독을 해제하고 돌아오면 다시 연결합니다. 주기적 전체 조회나 접속 확인용 하트비트는 없습니다. 사용하지 않는 탭을 닫으면 연결 수도 줄어듭니다.
- 교사의 전체 백업은 누를 때 개인 게시글과 최종 결과를 읽습니다. 7일 만료는 자동 삭제가 아니므로 보관 후 수업을 삭제합니다.

실제 사용량은 학생 수·게시 횟수·활성 탭 수·같은 프로젝트의 다른 앱에 따라 달라집니다. Firebase 콘솔 Realtime Database의 Usage에서 연결 수와 다운로드를 확인합니다. 무료 한도와 요금은 공식 안내를 확인합니다.
