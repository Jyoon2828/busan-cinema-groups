# 부산 영화관 탐험대 · 모둠 수업용

모둠이 영화관을 조사하고, 지역 영화관의 의미를 토의해 제출한 뒤 전자칠판에서 발표하는 웹앱입니다. 개인용 앱과 별도 프로젝트이며, 기존 개인 기록을 바꾸지 않습니다.

## 수업 흐름

1. 교사가 Google 계정으로 들어와 수업을 만듭니다.
2. 여섯 모둠에 영화관을 하나씩 지정합니다. 모둠이 직접 고르게 하려면 해당 모둠을 자유 선택으로 둡니다.
3. 교사가 모둠별 입장 링크나 QR을 나눠 줍니다. 모둠마다 대표 태블릿 한 대로 들어갑니다.
4. 모둠이 사진·읽기 자료에서 근거를 찾고 특징과 사람들에게 주는 도움을 정리합니다.
5. 의미 질문 중 필요한 것을 골라 토의하고, 영화관의 의미를 한 문장으로 정리합니다.
6. 모둠이 제출하면 교사 화면에 도착합니다. 교사가 모둠을 선택하면 연결된 전자칠판에 발표 자료가 표시됩니다.

학생은 이름·이메일·비밀번호를 입력하지 않습니다. 입장할 때 앱이 Firebase 익명 인증을 사용하며, 학생용 회원가입 화면은 없습니다. 공동 편집기처럼 여러 학생이 동시에 타이핑하는 방식이 아니라, 모둠 토의 결과를 대표 기기 한 대에서 정리하는 방식입니다.

## 조사할 영화관

- 롯데시네마 동래점
- 영화의전당
- 모퉁이극장
- 밀락수변 바다영화관
- CGV 센텀시티 IMAX
- CGV DRIVE IN 영도

자료 사진 17개는 앱에 포함되어 있습니다. 학생이 고른 근거의 ID와 작성한 글만 Firebase에 저장합니다. 사진별 출처는 [SOURCES.md](SOURCES.md)에서 확인합니다.

## 처음 설정할 때

이 ZIP에는 실제 수업에 연결된 Firebase 설정이 들어 있지 않습니다. 화면 미리보기와 실제 기기 간 수업 연결을 구분해 사용해 주세요.

1. [Firebase 연결 안내](docs/FIREBASE-SETUP.md)에 따라 Authentication과 Realtime Database를 준비합니다.
2. 제공한 `database.rules.json` 보안 규칙을 적용합니다. 테스트 모드의 전체 공개 규칙은 사용하지 않습니다.
3. 앱의 연결 설정에서 Firebase 웹 앱 설정을 넣고 `app-config.js`를 내려받아 프로젝트의 같은 파일을 교체합니다.
4. 배포 주소를 Firebase Authentication의 승인된 도메인에 추가하고, 교사 Google 로그인과 모둠 익명 입장을 확인합니다.

학생·교사·전자칠판이 서로 다른 기기에서 연동되려면 Firebase 설정과 보안 규칙 적용이 완료되어야 합니다.

## GitHub + Vercel에 올리기

ZIP의 압축을 풀고 **내용물 전체**를 새 GitHub 저장소의 최상위에 올립니다. 개인용 앱 저장소에 덮어쓰지 않습니다. `assets`와 `vendor` 폴더도 함께 올립니다.

Vercel에서 저장소를 가져와 Framework Preset을 **Other**, Root Directory를 기본 위치로 둡니다. 설치·빌드 명령은 필요하지 않습니다. Output Directory를 요구하면 `.`을 사용합니다. 기존 배포를 갱신할 때도 새 파일을 포함해 전체를 올립니다.

- 교사 화면: `?role=teacher`
- 전자칠판 화면: 교사 수업 화면에서 여는 전자칠판 링크 사용
- 학생 화면: 교사가 만든 모둠별 링크나 QR 사용

모둠별 링크에는 입장 키가 포함되어 있습니다. 수업 코드만으로 다른 모둠에 입장하는 방식이 아닙니다.

## 미리보기

주소 끝에 `?demo=1`을 붙이면 실제 Firebase 없이 흐름을 살펴볼 수 있습니다. 같은 브라우저의 여러 탭에서 교사·학생·전자칠판을 미리볼 수 있지만, 서로 다른 기기를 연결하는 실제 수업용 기능은 아닙니다. 미리보기 기록과 실제 수업 기록은 분리됩니다.

## 기록과 발표

- 입력 중에는 대표 기기의 브라우저에 초안을 저장합니다. 교사에게는 제출할 때 전송됩니다.
- 제출 완료 표시는 서버가 저장을 확인한 뒤 나타납니다. 전송 중이면 창을 닫지 말고 완료 표시를 확인합니다.
- 고칠 내용이 있으면 대표 기기에서 수정하고 다시 제출합니다.
- 교사가 영화관 배정을 바꾸면 이전 글을 보존하되 새 배정에 맞춰 확인하고 다시 제출해야 합니다.
- 수업은 생성 후 7일 동안 이용할 수 있습니다. 기간이 끝나면 보안 규칙이 접근을 막지만 데이터가 자동으로 삭제되지는 않습니다.
- 교사는 보관 기간이 끝나기 전에 수업 기록을 JSON으로 내려받고, 보관이 끝난 수업을 확인 후 삭제할 수 있습니다.

자세한 진행 방법은 [수업 사용 안내](docs/CLASSROOM-GUIDE.md), 사용량을 줄이는 구성은 [Firebase 사용량 안내](docs/LOW-USAGE.md)를 참고합니다.
