# 부산 영화관 탐험대 · 전자칠판 수업과 모둠 탐험

학생은 공통 링크 하나에서 모둠·번호·이름을 입력해 들어옵니다. 교사가 영화관을 지정하면 해당 모둠의 모든 학생 화면이 바뀝니다. 각자 질문 하나를 골라 개인 의견을 게시한 뒤, 모둠에서 생각을 모아 기록이 한 명이 소개와 의미를 제출합니다. 전자칠판에서는 사진과 두 항목을 한 화면에 띄워 발표합니다.

## 이번 버전으로 바꿀 때

1. ZIP의 압축을 푼 내용물 전체를 기존 모둠용 GitHub 저장소에 덮어 올립니다. `index.html`이 저장소 최상위에 있어야 합니다. `assets`, `vendor`, `lesson.js`를 포함합니다.
2. `app-config.js`에는 전달한 `busan-cinema-groups` 프로젝트의 연결 설정이 이미 들어 있습니다.
3. Firebase 콘솔의 **Realtime Database → 규칙**에서 이 ZIP의 **database.rules.json 전체**로 바꾸고 **게시**합니다. 개인 의견 게시판과 간단해진 제출 형식에 새 규칙이 필요합니다.
4. Vercel 배포가 완료되면 새로고침하고 **새 수업**을 만듭니다. 이전 버전의 수업 코드를 이어 쓰지 않습니다.
5. Authentication의 Google·익명 로그인과 Vercel 승인 도메인은 기존 설정을 유지합니다. 실제 학생 기기로 입장·게시·제출·발표를 한 번 시험합니다.

새 데이터는 `cinemaClassV3` 아래에 저장합니다. 이전 `cinemaGroupsV1`, `cinemaClassV2`의 규칙과 데이터는 보존합니다. 다른 종류 앱도 같은 프로젝트를 사용한다면 해당 앱의 규칙을 별도로 보존해야 합니다.

## 바뀐 활동

- 여섯 영화관의 사진 설명과 읽기 자료를 이전 분량의 약 두 배로 늘렸습니다. 긴 설명은 앞·다음 설명으로 나눠 읽습니다. 페이지 이동은 Firebase에 전송하지 않습니다.
- **자료 살펴보기 → 개인 의견 나누기 → 모둠 정리·제출**, 세 단계로 진행합니다.
- 의미 질문은 아래 세 개입니다. 학생마다 하나만 선택하고 자기 의견을 게시합니다. 다시 게시하면 본인의 기존 글을 바꿉니다.
  1. 영화관은 우리에게 어떤 즐거운 경험을 주나요?
  2. 다른 사람들과 함께 영화를 보고 생각을 나누면 어떤 점이 좋을까요?
  3. 우리 지역에 영화관이 있어서 좋은 점은 무엇인가요?
- 모둠 게시판에서 친구들의 의견을 읽고 토의합니다. 기록이 한 명이 **영화관 소개(120자 이내)**와 **영화관이 우리에게 주는 의미 한 문장(100자 이내)**을 정리합니다.
- 근거 담기, 근거 개수, 별도의 도움 정리 항목은 없습니다. 기록이도 먼저 자기 개인 의견 하나를 게시한 뒤 모둠 결과를 제출합니다. 모든 모둠원의 게시 완료를 제출 조건으로 강제하지는 않습니다.
- 발표는 사진·소개·의미가 동시에 보이는 한 화면입니다. 내용 탭이나 발표 글 페이지를 넘기지 않습니다. 저장한 PNG에도 같은 두 항목과 사진을 함께 담고, 출처는 한 줄만 넣습니다.

## 수업 시작

**교사 · 수업 준비**에서 Google 로그인 후 여섯 모둠 수업을 만듭니다. **학생 공통 링크 · QR**로 모든 학생에게 같은 주소를 안내합니다. 학생은 모둠·번호(1~40)·이름(20자 이내)을 입력합니다. 교사가 영화관을 지정하기 전에는 대기 화면을 보여 줍니다.

각자 자료를 읽고 개인 의견을 게시합니다. 같은 모둠 안에서만 서로의 의견을 볼 수 있습니다. 모둠에서 정한 기록이 한 명이 **내가 기록이**를 누르고 최종 두 항목을 작성·제출합니다. 타자를 실시간으로 합치는 공동 문서 방식은 아닙니다. 제출된 모둠 정리는 다른 모둠원도 읽을 수 있습니다.

교사 화면의 **개인 의견 N / M명**을 누르면 그 모둠의 게시글을 읽습니다. **전자칠판 수업 열기**는 수업을 만든 Google 계정으로 엽니다.

## 전자칠판의 13개 수업 장면

1. 우리 동네 영화관 탐험대
2. 영화관에서 함께한 기억
3. 부산의 여섯 영화관 사진
4. 자료 조사 → 개인 의견 → 모둠 정리·발표
5. 학생 공통 링크·QR 입장 안내
6. 사진과 설명 살펴보기
7. 영화관 소개 준비
8. 세 질문 중 하나 골라 개인 의견 게시
9. 모둠 게시판의 생각 함께 읽기
10. 모둠의 의미를 한 문장으로 정리
11. 소개와 의미 두 항목 확인·제출
12. 실제 제출 자료로 한 화면 모둠 발표
13. 배움 돌아보기

**차례**에서 원하는 장면으로 이동합니다. 방향키·PageUp/PageDown도 지원합니다. 세 의미 질문은 한 화면에 모두 보여 줍니다. 타이머는 종료 시각만 한 번 보내고 기기 안에서 시간을 계산합니다.

## GitHub + Vercel

ZIP 자체가 아니라 압축을 푼 내용물을 올립니다. Vercel Framework Preset은 **Other**, 빌드 명령은 비워 둡니다. Output Directory가 필요하면 `.`을 사용합니다.

`?demo=1`은 같은 브라우저 여러 탭에서만 연결되는 연습 모드입니다. 실제 수업 링크에는 `demo=1`을 넣지 않습니다. 연습 기록은 Firebase에 보내지 않습니다.

## 정보나 기록이를 바꿀 때

- 번호가 이미 사용 중이면 다른 기기에서 가져갈 수 없습니다. 교사 화면의 **참여 학생 → 입장 초기화** 후 다시 입장합니다. 모둠·번호·이름을 잘못 입력한 경우도 같습니다.
- 입장 초기화는 해당 학생의 입장 정보와 개인 의견을 지웁니다. 모둠의 최종 제출본은 남습니다.
- **기록이 변경** 후 새 기록이가 자신의 기기에서 역할을 맡습니다. 기존 글을 고칠 때는 **모둠 제출본 보기 → 이 제출본을 불러와 수정하기**를 누릅니다.
- 영화관을 다시 지정하면 이전 영화관의 기기 메모와 최종 제출본은 보관합니다. 새 영화관으로 개인 의견을 다시 게시하고 모둠 결과를 다시 제출해야 발표할 수 있습니다. 이전 영화관 의견은 현재 게시판·참여 수에서 제외합니다.
- 수업 생성 후 7일 동안 학생이 이용할 수 있습니다. 만료는 접근 제한이며 자동 삭제가 아닙니다. 보관 후 수업을 삭제하면 입장 정보·개인 의견·모둠 정리를 함께 지웁니다.
