# 부산 영화관 탐험대 · 전자칠판 수업과 모둠 탐험

학생은 공통 링크 하나에서 모둠·번호·이름을 입력해 들어옵니다. 교사가 영화관을 지정하면 해당 모둠의 모든 학생 화면이 바뀝니다. 모둠 토의 결과는 모둠에서 정한 기록이 한 명이 제출하고, 교사는 전자칠판의 PPT형 수업 화면에서 사진과 글을 띄워 발표를 진행합니다.

## 이번 버전으로 바꿀 때

1. 이 ZIP의 압축을 푼 내용물 전체를 기존 모둠용 GitHub 저장소에 덮어 올립니다. `lesson.js`도 새로 포함되어야 합니다. 개인용 앱 저장소는 그대로 둡니다.
2. `app-config.js`에는 전달한 `busan-cinema-groups` Firebase 프로젝트의 웹 연결 설정이 이미 들어 있습니다.
3. Firebase 콘솔의 **Realtime Database → 규칙**에서 이 ZIP의 **database.rules.json 전체**로 바꾸고 **게시**합니다. 이번 버전은 학생 입장 방식과 권한이 바뀌어 이전 규칙으로는 작동하지 않습니다.
4. Vercel 배포가 완료되면 새로고침하고 **새 수업**을 만듭니다. 이전 모둠 전용 링크 수업의 코드는 이번 버전에 이어 쓰지 않습니다.
5. Authentication의 Google·익명 로그인과 Vercel 승인 도메인은 기존 설정을 유지합니다. 실제 기기로 입장·제출·발표까지 한 번 시험합니다.

데이터는 `cinemaClassV2` 아래에 저장됩니다. 예전 `cinemaGroupsV1`의 데이터는 삭제하거나 변환하지 않습니다. 제공한 규칙에는 예전 모둠용 앱의 규칙도 함께 들어 있습니다. 다른 종류의 앱이 같은 Firebase 프로젝트를 사용 중이라면 그 앱의 규칙을 별도로 보존해야 합니다.

## 수업 시작

- **교사 · 수업 준비**: Google 로그인 → 여섯 모둠 수업 만들기.
- **학생 공통 링크 · QR**: 모든 학생에게 같은 주소 하나를 안내합니다.
- 학생은 모둠, 번호(1~40), 이름(20자 이내)을 입력합니다. 별도 계정 가입 화면은 없습니다.
- 교사가 각 모둠의 영화관을 선택하면 바로 저장되고, 해당 모둠 학생들의 자료 화면이 바뀝니다. 지정 전에는 대기 화면을 보여 줍니다.
- 각자 자료를 살펴보고 메모합니다. 기록이 한 명이 **내가 기록이**를 눌러 역할을 맡고, 모둠에서 함께 정리한 결과를 제출합니다.
- **전자칠판 수업 열기**를 전자칠판에서 열고 수업을 만든 같은 Google 계정으로 로그인합니다.

학생 모두가 자료와 메모 화면을 사용할 수 있습니다. 다른 학생의 타자를 실시간으로 합치는 공동 문서 편집 방식은 아닙니다. 모둠의 최종 결과는 기록이가 모아 제출합니다. 다른 모둠원도 제출된 모둠 정리를 볼 수 있습니다.

## 전자칠판의 13개 수업 장면

1. 우리 동네 영화관 탐험대
2. 영화관에서 함께한 기억
3. 부산의 여섯 영화관 사진
4. 자료 조사 → 의미 토의 → 발표 흐름
5. 학생 공통 링크·QR 입장 안내
6. 사진과 글에서 단서 찾기
7. 특징·근거·도움 정리
8. 즐거움의 의미 토의
9. 함께 보는 경험의 가치 토의
10. 우리 지역 문화 공간의 의미 토의
11. 한 문장 정리와 제출
12. 실제 제출 자료로 모둠 발표
13. 배움 돌아보기

질문은 **다음 질문**을 누르면 하나씩 나타납니다. 아래쪽 **차례**에서 원하는 장면으로 이동할 수 있습니다. 방향키·PageUp/PageDown도 지원합니다. 타이머는 시작 정보를 한 번만 보내고 기기 안에서 시간을 계산합니다.

발표 화면의 특징과 도움, 영화관의 의미, 조사 근거를 전환할 수 있습니다. 긴 글은 짧은 쪽으로 나누어 보여 줍니다. 사진·기록 저장 기능의 출처는 한 줄입니다.

## GitHub + Vercel

파일을 압축 그대로 올리지 말고, `index.html`이 저장소 최상위에 보이도록 내용물 전체를 올립니다. `assets`와 `vendor` 폴더도 필요합니다. Vercel Framework Preset은 **Other**, 빌드 명령은 비워 둡니다. Output Directory를 입력하라고 하면 `.`을 사용합니다.

`?demo=1`은 같은 브라우저 여러 탭에서만 연결되는 연습 모드입니다. 실제 수업 링크에는 `demo=1`을 넣지 않습니다. 연습 기록은 실제 Firebase에 전송하지 않습니다.

## 기기·모둠 정보와 기록이를 바꿀 때

- 번호가 이미 사용 중이면 다른 기기에서 그 번호를 가져갈 수 없습니다. 교사 화면의 **참여 학생 → 입장 초기화** 후 다시 입장합니다.
- 학생의 모둠·번호·이름을 잘못 입력한 경우에도 입장 초기화 후 다시 입력합니다.
- 기록이를 바꾸려면 **기록이 변경**을 누르고 새 기록이가 자신의 태블릿에서 역할을 맡습니다. 모둠 제출물은 남아 있습니다.
- 새 기록이가 이미 제출한 글을 고치려면 **모둠 제출본 보기 → 이 제출본을 불러와 수정하기**를 사용합니다.
- 영화관을 다시 지정해도 이전 영화관의 메모는 기기에 보관합니다. 기존 제출본은 남지만, 현재 지정된 영화관으로 다시 제출해야 발표할 수 있습니다.
- 수업은 생성 후 7일 동안 학생이 이용할 수 있습니다. 기간 만료는 접근 제한이며 자동 삭제가 아닙니다. 교사는 제출 기록을 저장한 뒤 수업을 삭제할 수 있습니다.
